ШАЙТАНАТ — программа узбекско-русского параллельного корпуса
Версия 1.1 (23.10.2026), открытая версия

ЗАПУСК
   Shaytanat.exe (из раздела Releases) запускается двойным щелчком, Python не нужен.
   Из этой папки: двойной щелчок по START.bat (нужен Python 3.9+).
   Собрать свой Shaytanat.exe: двойной щелчок по BUILD_EXE.bat, файл появится в папке dist.
   Если Windows покажет «Windows защитила ваш компьютер», нажмите «Подробнее», затем «Выполнить в любом случае».

ПЕРЕВОДЧИК
   Вкладка «Переводчик», поле «Ключ API», вставьте свой ключ, «Сохранить ключ».
   Ключ хранится только на этом компьютере (%APPDATA%\Shaytanat\config.json).
   Каждый перевод списывает небольшую сумму со счёта, к которому привязан ключ.
   Никогда не передавайте свой ключ вместе с программой.
   Без интернета и без ключа работает всё, кроме переводчика.

ОТКРЫТАЯ ВЕРСИЯ
   Полностью приведены 235 предложений эксперимента машинного перевода.
   Из остального текста показаны фрагменты вокруг размеченных единиц.
   Полная версия корпуса предоставляется по запросу для научных целей.
