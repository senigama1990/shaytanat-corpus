# Шайтанат: узбекско-русский параллельный корпус

**Сайт:** https://senigama1990.github.io/shaytanat-corpus/
**Программа для Windows:** [Releases](https://github.com/senigama1990/shaytanat-corpus/releases/latest) → `Shaytanat.exe`

Параллельный корпус первой книги романа Тахира Малика «Шайтанат» и её русского перевода (Т.Нармирзаев, М.Алимов, 2016). Корпус включает разметку культурно маркированных единиц (КМЕ), таблицу антропонимов и эксперимент машинного перевода с десятью системами.

| Показатель | Значение |
|---|---|
| Предложения uz / ru | 12.410 / 11.569 |
| Связки (выравнивание LaBSE) | 11.644, из них 1-1 9.479 (81,4%) |
| КМЕ | 2.507: устойчивые выражения 1.002, реалии 689, субстандартная лексика 502, обращения 314 |
| Антропонимы | 77 имён, 4.394 употребления |
| Сноски переводчика | 60 |
| Эксперимент МП | 240 КМЕ в 235 предложениях; S1–S4 (Opus 5.5, Sonnet 5.5), Tilmoch, Google, Yandex, NLLB-600M, NLLB-1.3B, NLLB-600M дообученная |

## Что в репозитории

* `docs/` открытая версия сайта (GitHub Pages);
* `app/` программа «Шайтанат» для Windows: поиск, разметка, эксперимент и переводчик. Переводчик работает с ключом API, который каждый пользователь вводит сам; ключ хранится только на его компьютере (`%APPDATA%\Shaytanat\config.json`) и в репозиторий не попадает;
* `data/` разметка в CSV (UTF-8, разделитель `;`) и в одном файле Excel `Shaytanat_razmetka.xlsx`.

| Файл | Содержание |
|---|---|
| `kme.csv` | 2.507 КМЕ: класс, подкласс, форма, код приёма в S0, стратегия, реализация в S0 |
| `anthroponyms.csv`, `anthroponym_occ.csv` | 77 антропонимов и 4.394 их употребления |
| `links.csv` | 11.644 связки: тип, близость LaBSE, помета (без текста) |
| `mt_sample.csv`, `mt_outputs.csv` | выборка из 240 КМЕ и переводы 235 предложений десятью системами |
| `mt_annotation.csv`, `mt_metrics.csv` | разметка машинного перевода, неудачи, chrF, BLEU, TER |
| `codes.csv` | коды переводческих приёмов |

## Открытая и полная версии

Роман и его перевод охраняются авторским правом. В открытой версии полностью приведены 235 предложений эксперимента; из остального текста показаны фрагменты по 5 слов слева и справа от размеченных единиц и до 5 примеров на антропоним. Полная версия корпуса с текстами предоставляется по запросу для научных целей.

## Сборка программы

Файл `Shaytanat.exe` собирается автоматически (GitHub Actions, `.github/workflows/build-exe.yml`) при каждом изменении программы или данных (номер версии в файле `VERSION`). На своём компьютере программу можно запустить через `app/START.bat` (нужен Python 3.9+) или собрать через `app/BUILD_EXE.bat`.
