**Shaytanat.exe** программа для Windows: поиск по корпусу, разметка КМЕ, эксперимент машинного перевода, антропонимы и переводчик (S1, S2, S3). Запуск двойным щелчком, Python не нужен. Если Windows покажет «Windows защитила ваш компьютер», нажмите «Подробнее», затем «Выполнить в любом случае»: так бывает с программами без платной цифровой подписи.

Переводчику нужен ключ API: вкладка «Переводчик», поле «Ключ API», кнопка «Сохранить ключ». Ключ хранится только на вашем компьютере. Без ключа работает всё, кроме переводчика.

**Shaytanat_data.zip** таблицы разметки (CSV и Excel).
